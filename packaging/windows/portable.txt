pdf.SMT portable mode

While this file sits next to pdfcraft.exe, pdf.SMT keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the pdf.SMTData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move pdf.SMT with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\pdf.SMT and
%LOCALAPPDATA%\pdf.SMT) instead. If pdf.SMTData can't be written (for example on a read-only
drive), pdf.SMT says so and uses the per-user folders instead.
